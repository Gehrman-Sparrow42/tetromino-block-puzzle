# Offline typefaces

These unmodified variable fonts are bundled locally and embedded in the single-file production build. Gameplay never requests fonts from the network. Only the nine Impeccable theme treatments use them; the four original themes retain their existing type.

| Typeface         | Use                                          | Official source                                                                      | License                                                          |
| ---------------- | -------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| Familjen Grotesk | Menus, controls, settings and tabular scores | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/familjengrotesk) | SIL Open Font License 1.1, included in `FamiljenGrotesk-OFL.txt` |
| Newsreader       | Movement Score and Botanical Folio headings  | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/newsreader)      | SIL Open Font License 1.1, included in `Newsreader-OFL.txt`      |

Downloaded from the official Google Fonts repository on 2026-10-21. Font declarations use `font-display: swap`; the interface remains usable while the local fonts decode.
