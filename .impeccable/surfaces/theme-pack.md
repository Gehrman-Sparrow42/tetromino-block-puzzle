# Afterblock theme pack

## Brief and approval

The user asked for a complete new theme using Impeccable, then explicitly requested all the designs shown on the localhost decision page, including the smaller alternative cards. Build nine new selectable themes, preserving the four existing themes, gameplay, saves, short functional labels, large board and configurable controls. This approval covers the complete set; no single-card choice is needed.

## Direction contract

- **THESIS:** Give the same familiar game nine complete, recognizable visual treatments, each usable for long phone play.
- **OWN-WORLD:** Each theme owns its interface palette, typography, control shapes and Canvas tile grammar. Basalt is chalk and faceted holds; Workshop is enamel modular toys; Night Sleeve is matte catalog graphics; Movement Score is printed notation; Botanical Folio is cream/green/berry; Gate Board is navy/amber tabular clarity; Design Annual is near-white/periwinkle precision; Data Field is static black/ivory patterns; Classic Arcade is bright flat arcade color.
- **STORY:** Start from the existing main menu, choose a mode, play on the dominant board, pause and change the theme in Settings without losing the run. The theme follows through home, hold/next, ghost, controls, settings, records and results.
- **FIRST VIEWPORT:** Compact score/lines/level/time row, horizontal hold/next strip, large board and translucent thumb controls. Preserve the current information architecture and geometry; use the visual systems for type, palette, density and one tile/control signature rather than themed interface costumes.
- **FORM:** Operate mode, code-first. Direction reference `seed:247a72cc024d6ae5`. Nine complete themes in addition to Ink, LCD, Neon and Paper; themes stay user-selectable and preferences persist.

## Quality requirements

- Preserve current saved runs, control settings, existing themes and engine rules.
- Keep game controls and settings sliders/dropdowns at least 48 CSS pixels in their tested dimensions.
- Bundle any new fonts locally, with their licenses; the standalone HTML and Android app must remain offline.
- Preserve visible keyboard focus and readable normal text contrast. No strobing, decorative overlays or new slogans.
- Data Field and Movement Score distinguish all seven pieces through static internal patterns in addition to silhouette.
- Match distinct renderer treatments in board, hold and next previews; ghost outlines stay subordinate and readable.
- Inspect phone, compact phone, desktop, home, settings, paused and live game views; execute browser tests and installed-Android smoke checks.
